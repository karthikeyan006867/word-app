# 🚀 Quick Start Guide

Welcome to your Premium Word Processor! This guide will help you get started in minutes.

## ⚡ Installation (2 minutes)

```bash
# 1. Navigate to project directory
cd word-app

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) - Your word processor is ready! 🎉

## 🎯 First Steps

### 1. Start Writing
- Click anywhere in the white document area
- Start typing immediately
- Your document auto-saves every 30 seconds

### 2. Format Your Text
**Quick Formatting:**
- `Ctrl+B` - Bold
- `Ctrl+I` - Italic
- `Ctrl+U` - Underline

**Use the Toolbar:**
- Select text
- Click formatting buttons
- Choose fonts, sizes, colors

### 3. Document Structure
**Add Headings:**
- Select "Heading 1/2/3" from toolbar
- Or use Format menu

**Create Lists:**
- Click bullet or numbered list icons
- Press Enter for new items

### 4. Insert Elements
**Add Links:**
1. Select text
2. Click link icon
3. Enter URL
4. Done!

**Insert Images:**
1. Click image icon
2. Enter image URL
3. Image appears in document

**Add Tables:**
1. Click table icon
2. Enter rows and columns
3. Start filling data

### 5. Save & Export

**Auto-Save:**
- Automatic every 30 seconds
- Saved in browser storage
- Green indicator shows status

**Manual Save:**
- Press `Ctrl+S`
- Or click File → Save

**Export Your Document:**
1. Click File menu
2. Choose "Export as..."
3. Select format:
   - PDF (for sharing)
   - DOCX (Word compatibility)
   - HTML (web publishing)
   - Markdown (developer-friendly)
   - Text (simple format)

## 📊 Understanding the Interface

### Top Bar
- **Document Title** - Click to rename
- **Menu Bar** - File, Edit, View, Insert, Format, Tools, Help
- **Zoom Level** - Shows current zoom (50-200%)

### Toolbar (Below Menu)
- **Undo/Redo** - First two buttons
- **Font Controls** - Font family, size
- **Text Formatting** - Bold, italic, etc.
- **Colors** - Text color, highlight
- **Alignment** - Left, center, right, justify
- **Lists** - Bullet, numbered
- **Insert** - Link, image, table

### Sidebar (Left - Toggle with ☰)
- **Document Stats** - Words, characters, pages
- **Last Saved** - Auto-save status
- **Document Outline** - Navigate headings
- **Reading Time** - Estimated time
- **Quick Actions** - Copy stats

### Editor Area (Center)
- **White Page** - Your document
- **Margins** - Customizable via Page Layout
- **Zoom** - Change via View menu
- **Print Preview** - What you see is what you print

## 🐛 Troubleshooting

### Document Not Saving?
- Check browser storage isn't full
- Try manual save (Ctrl+S)
- Export as backup

### Formatting Not Working?
- Select text first
- Then apply formatting
- Check toolbar for active state

### Lost Your Document?
- Check Version History
- Look in browser's local storage
- Restore from last auto-save

### Export Failing?
- Check file size isn't too large
- Try different format
- Ensure popup blocker is off
